## 一句话概括

底是纯黑，面板只比它亮一点点，全靠 1px 描边分层。颜色集中在两个地方：流体玻璃统计卡，和一个用得很克制的绿。

## 绿只有三种用法

主绿 `#0ac98c` = `hsl(161, 90%, 41%)`，偏青的翠绿。
参考里最亮的绿只出现在一个直径 9px 的点上——别把它当大面积填充。

1. **信号点**：纯色圆点 + 光晕 `0 0 12px 55%` + 3px 光圈 `14%`。用于在跑状态、导航选中、日历今天。
2. **深绿实底**：主按钮。底 = 主绿降到 `L 11%`，描边 = 主绿 `34%`，字用白 `#f2fbf6`。悬停底提到 `L 15%`。
3. **绿字徽章**：底 = 主绿 `13%`，字 = 主绿提到 `L 62%`。用于「待办」「高优先级」这类小标签，和 `↑ 20%` 这类涨幅绿字（字直接用 `L 60%`）。

### 换主色

整套只认一个主色。换色时保持 S、L 不变只换 H；候选：`#0ac98c`（默认）/ `#00d1ff` / `#7b6bff` / `#c9ccc8`。

## 流体玻璃卡（整套里唯一的彩色面）

三团色球压在暗底上，重模糊，上面盖暗罩保证白字可读，最后补左上高光。

```css
/* 卡壳 */
background: #080b0a;
border: 1px solid rgba(255,255,255,.07);
border-radius: 16px;
overflow: hidden;
position: relative;

/* 色球层：inset -18% 让球出框，blur 才不露边 */
position: absolute; inset: -18%;
filter: blur(30px);
opacity: .82;
/* 每个球 width 44~52% · height 50~62% · border-radius: 50%
   颜色 = hsl(主绿色相 + 偏移, 主绿饱和度 × 0.75~1.0, L 20~33%) */

/* 暗罩，保证白字可读 */
background: linear-gradient(168deg, rgba(0,0,0,.18), rgba(0,0,0,.52));

/* 左上高光 */
background: linear-gradient(158deg, rgba(255,255,255,.08), transparent 44%);
```

四张卡的色相是连着往琥珀走的，不是四套独立配色（三个数分别是三个色球的色相偏移）：

| 卡 | 色相偏移 |
|---|---|
| 卡 01 | +0° / +16° / −22° |
| 卡 02 | −10° / +12° / −34° |
| 卡 03 | −58° / −92° / −24° |
| 卡 04 | −104° / −122° / −80° |

动效：色球缓慢漂移，`19–27s` `ease-in-out alternate`，位移 9% / 缩放 1.22，各球错开负延迟。

## 3D 卡环（可选组件）

聚焦卡：发光绿实底（`linear-gradient(155deg, 主绿 L62%, 主绿 L36%)`）+ `0 0 44px` 绿光晕；两侧卡：淡灰白（`#eef2ef → #cfd6d2`）带 `rotateY(±24°/±34°)` 透视，`perspective: 1000px`。

## 禁区

- 大面积绿色填充、霓虹绿、绿底黑字按钮
- 给整页铺绿光晕（背景保持纯黑）
- 大数字加粗（一律 mono 400）
- 超过 1px 的描边
