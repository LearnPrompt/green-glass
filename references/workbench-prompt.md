# 绿透工作台 · 生成提示语模板

一段填空式提示语。填好占位符后丢给任何 AI 编码工具（Claude Code / Cursor / Codex / v0 等），生成一个绿透风格的个人工作台 Web 应用。

## 占位符

| 占位符 | 填什么 | 示例 |
|---|---|---|
| `{{REFERENCE_IMAGE}}` | 参考图说明或图片引用；没有就删掉这一句 | `参考附图` |
| `{{PROJECT_FOLDER}}` | 生成代码的目标目录 | `~/projects/my-workbench` |
| `{{WORKSPACE_NAME}}` | 侧边栏工作区名 | `CARL Workbench` |
| `{{WORKSPACE_SUBTITLE}}` | 工作区副标题 | `个人操作系统` |
| `{{CONTENT_PLATFORM_1..3}}` | 你的内容平台 | `公众号` / `视频号` / `小红书` |

## 提示语正文（复制以下整段）

```
{{REFERENCE_IMAGE}} 在文件夹 {{PROJECT_FOLDER}} 中，基于参考图片（仅参考信息架构与视觉基调，不逐像素复制），设计并实现一个个人工作台 / 个人操作系统 Web 应用，作为每天打开就能知道今日重点的个人指挥中心，融合仪表盘 + 任务管理 + 学习 / 编程 / 阅读 / 内容中心。

布局：左侧侧边栏（{{WORKSPACE_NAME}}，副标题 {{WORKSPACE_SUBTITLE}}；分组 总览 / 工作 / 生活 / 创作 / 资料库：仪表盘、今日、学习、编程、阅读、周末、内容、资料库、设置、头像，支持收起）+ 顶部栏（⌘K 快速添加命令面板，可搜索 任务 / 项目 / 笔记 / 页面）+ 中央宽阔仪表盘。

仪表盘按视觉层级组织：问候区（问候语 + 日期 / 天气 / 连续打卡天数）；今日聚焦（仅最重要的 3 件事：标题 / 分类 / 预估时间 / 优先级 / 复选框，强调专注而非数量）；下一个待办（醒目卡片 + 全页最容易点击的「开始专注」按钮，点击启动专注计时器并标记进行中）；今日日程（简约垂直时间线）；进行中的项目（进度 + 下一步行动）；正在学 / 正在做 / 待读队列（各不超过 3 项，支持 继续、打开、标记已读）；内容工作室（灵感 + {{CONTENT_PLATFORM_1}} / {{CONTENT_PLATFORM_2}} / {{CONTENT_PLATFORM_3}} 草稿）；周末（临近周末才放大，平日保持极小）。

视觉采用「绿透」暗色流体玻璃体系，严格执行以下取值：页面底纯黑 #000000，面板 #0a0e0c、侧栏 #050807、卡中卡 #101613、选中态 #1b211e，面板之间不靠阴影靠 1px rgba(255,255,255,.06) 描边分层；主绿 #0ac98c 只有三种用法——① 信号点（9px 圆点 + 0 0 12px 55% 光晕 + 3px 光圈 14%，用于在跑状态与导航选中），② 深绿实底主按钮（底 = 主绿降到 L11%，描边 = 主绿 34%，白字，胶囊圆角），③ 绿字徽章（底 = 主绿 13%，字 = 主绿提到 L62%）——除此之外绿不出现，禁止大面积绿色填充与霓虹绿；顶部一排 3–4 张流体玻璃统计卡是全页唯一的彩色面：卡壳 #080b0a + 1px 描边，内部三团色球（hsl 主绿色相 ± 偏移，L 20–33%）blur(30px)、opacity .82，其上盖 linear-gradient(168deg, rgba(0,0,0,.18), rgba(0,0,0,.52)) 暗罩保证白字可读，再补左上 rgba(255,255,255,.08) 高光，四张卡色相依次向琥珀方向偏移并带 19–27s 缓慢漂移动画；文字阶 #f4f8f6 / 62% / 45% / 34%，大数字用等宽字体 34px 400 字重（靠字号不靠加粗），mono 小标签 9.5px 全大写字距 .14em；状态色 琥珀 #ffb457 / 告警橙 #ff8f6b / 风险红 #ff7d6b；字体 Space Grotesk（中文回落苹方）+ JetBrains Mono（开 tnum）；圆角 面板 16px、导航项 12px、按钮与输入框胶囊 999px。整体安静、克制、编辑感，避免过强渐变发光和对比度不足。

技术：若已有代码仓库则先分析并复用现有组件，否则默认 React + TypeScript + Tailwind CSS + Lucide Icons；组件必须拆分（侧边栏、顶部栏、今日聚焦、下一个待办、命令面板等，勿写单文件）；使用真实感模拟数据（任务含 id / 标题 / 分类 / 优先级 / 状态 / 截止日期 / 预估分钟数，及项目、阅读项、内容项结构），暂不做后端 / 认证 / API 集成。

微交互克制：悬停提亮、复选框完成动画 + 删除线、专注计时器、侧边栏收起。

响应式：桌面端优先，平板端收起侧边栏，移动端改为底部导航（今日 / 学习 / 编程 / 阅读 / 更多）+ 单列卡片。

核心是做好布局 + 用户体验 + 视觉层级，让它成为一个安静、有秩序、愿意每天打开的绿透个人控制中心。
```

## 可选亮色 variant

想要亮色版时，把上面「视觉」整段替换为：

```
视觉采用透明绿毛玻璃风格：鼠尾草绿 / 薄荷绿 / 翡翠绿 低饱和绿点缀色 + 暖白色底色；半透明磨砂卡片（细微边框、14–16px 圆角、柔和模糊、极轻阴影）；深绿仅用于重点按钮和激活状态；整体如 Linear × Notion × Arc，安静、极简、编辑感，避免霓虹绿、过强渐变发光和对比度不足。
```

完整数值取自 [design-tokens.md](design-tokens.md)，实现时以那张表为准。
